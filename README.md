# 🍺 Sistema ERP para Licorería y Bar

Sistema web de gestión integral diseñado para controlar operaciones en tiempo real de un local comercial (inventario, mesas/cuentas, ventas, control de caja y métodos de pago múltiples).

---

## 🚀 Características Principales
* **Gestión de Cuentas y Mesas:** Control de consumo por mesa o cliente con actualización en tiempo real y sincronización de stock automática.
* **Múltiples Métodos de Pago:** Soporte para cobros en Efectivo, Yape, Plin, Tarjeta y **Pago Mixto** con desglose detallado.
* **Control de Caja y Arqueo:** Registro de aperturas, ingresos, egresos y control de ventas por turno.
* **Gestión de Inventario:** Control de stock por unidades, cajas o presentaciones con alertas de stock mínimo.

---

## 🛠️ Tecnologías Utilizadas
* **Backend:** Node.js, Express
* **Base de Datos:** MySQL (XAMPP / MariaDB)
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
